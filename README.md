# Ζωντανεύοντας την Αρχαία Κέρκυρα — M1

Το project περιέχει το πρώτο λειτουργικό AR station για τη Γοργώ.

## Περιεχόμενα

- `index.html` — Web AR σκηνή
- `ar.js` — χειρισμός αναγνώρισης/απώλειας marker
- `targets/corfu.mind` — MindAR image target που δημιουργήθηκε από τον marker
- `assets/images/M1_Gorgon_marker_source.jpg` — η προετοιμασμένη εικόνα-marker

## Τεχνολογία

- A-Frame 1.5.0
- MindAR 1.2.5
- Web AR μέσω browser
- `targetIndex: 0` για το M1

## Εκτέλεση

Το project χρειάζεται web server. Δεν πρέπει να ανοίγει ως απλό `file://`, επειδή η κάμερα και τα modules του browser έχουν περιορισμούς.

Μπορεί να ανέβει σε GitHub Pages ή να τρέξει από local server.

## Τρέχουσα υλοποίηση M1

Όταν η κάμερα αναγνωρίσει το marker:
1. εμφανίζεται τίτλος «ΓΟΡΓΩ»,
2. εμφανίζεται ένα διακριτικό animated AR halo,
3. εμφανίζεται πληροφοριακό πλαίσιο,
4. ενημερώνεται η οδηγία χρήσης.

Σημείωση: το τρέχον M1 χρησιμοποιεί ερμηνευτικό AR layer και όχι αυθαίρετο 3D reconstruction. Το πραγματικό 3D asset μπορεί να προστεθεί αργότερα, όταν επιλεγεί και τεκμηριωθεί κατάλληλο μοντέλο.

## Επόμενα

- προσθήκη ηχητικής αφήγησης,
- επιλογή/τεκμηρίωση 3D asset ή 2.5D reconstruction,
- M2: Λέων του Μενεκράτη,
- M3: αέτωμα Διονυσιακού συμποσίου,
- M4: τεκμηριωμένο επιλεγμένο έκθεμα,
- τελικό testing σε κινητό,
- GitHub Pages deployment.
