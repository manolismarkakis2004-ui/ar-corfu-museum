# Ζωντανεύοντας την Αρχαία Κέρκυρα

## Περιγραφή

Το «Ζωντανεύοντας την Αρχαία Κέρκυρα» είναι μια διαδραστική εμπειρία Web AR που σχεδιάστηκε για το Αρχαιολογικό Μουσείο Κέρκυρας.

Η εμπειρία χρησιμοποιεί τεχνολογία Marker-Based Augmented Reality, επιτρέποντας στον επισκέπτη να χρησιμοποιήσει την κάμερα του κινητού του μέσω web browser και να ανακαλύψει ψηφιακό περιεχόμενο σε συνδυασμό με επιλεγμένα εκθέματα του μουσείου.

Δεν απαιτείται εγκατάσταση εφαρμογής.

## Στόχος

Στόχος της εφαρμογής είναι να δημιουργήσει ένα επιπλέον επίπεδο ερμηνείας των εκθεμάτων, συνδυάζοντας:

- πραγματικά αρχαιολογικά αντικείμενα
- επαυξημένη πραγματικότητα
- οπτική πληροφορία
- ηχητική αφήγηση
- διαδραστική εξερεύνηση

Η ψηφιακή πληροφορία λειτουργεί συμπληρωματικά προς το πραγματικό έκθεμα και δεν αντικαθιστά την εμπειρία του μουσείου.

## Διαδραστική εμπειρία

Ο επισκέπτης ακολουθεί μια σύντομη AR αποστολή και αναζητά τέσσερα επιλεγμένα εκθέματα:

1. Γοργώ
2. Λέων του Μενεκράτη
3. Αέτωμα του Διονύσου
4. Κούρος

Κάθε έκθεμα αντιστοιχεί σε διαφορετικό image marker.

Με την αναγνώριση του marker εμφανίζεται ένα ψηφιακό επίπεδο πάνω από το φυσικό έκθεμα, ενώ ο επισκέπτης λαμβάνει πληροφορίες και ηχητική αφήγηση.

Η εμπειρία είναι σχεδιασμένη ως μια σύντομη γραμμική διαδρομή:

**Τι βλέπω; → Από πού προέρχεται; → Τι μας λέει; → Πώς το κατανοούμε σήμερα;**

## Τεχνολογίες

Η εφαρμογή βασίζεται στις παρακάτω τεχνολογίες:

- HTML5
- CSS3
- JavaScript
- A-Frame
- MindAR
- Web Camera API
- Web Speech API
- GitHub Pages

Το MindAR χρησιμοποιείται για την αναγνώριση των image targets και την ενεργοποίηση του αντίστοιχου AR περιεχομένου.
